# Mistakes and their guards

A mistake is written here only together with the guard that now catches it: the test that fails
without its fix, named by its file and words that stand in it (`tests/structure.test.mjs` checks
that the words are in that file). A mistake no test catches says so, "unguarded:" and why, so
nothing reads as guarded that is not. One row per line. No diary: replace rows when a better guard
appears.
